# Serving-path dependencies for the FastAPI image (P1-1).
#
# This mirrors pyproject.toml's core `dependencies` plus the `llm` extra, and
# deliberately omits everything the 24/7 API never imports:
#
#   • torch          — installed separately in the Dockerfile from the CPU wheel
#                      index. pyproject pins it to the CUDA 12.8 channel for the
#                      workstation (WhisperX, GPU rerank); that build is ~3 GB
#                      and useless on a CPU-only VPS.
#   • pandas,        — the `api` extra. Nothing under api/ imports either one;
#     python-multipart  the CSV exporters use stdlib csv + io, and there are no
#                      file uploads.
#   • collection, asr, cleaning, extraction, ui, orchestration, observability
#                    — all workstation-side. The pipeline does not run here.
#
# Keep in sync with pyproject.toml by hand. If a new serving-path import lands
# and is missing here, the container fails at boot, not silently at request
# time — api/main.py's lifespan warm-up touches the retrieval stack eagerly.
